# Logos

The Menab logo is a folded "M" mark next to the Menab wordmark. These files were made from the original logo Ibrahim supplied; only the color changed, never the shape.

- `menab-logo-light.png`: off-white (`ink` dark value) for the website and anything on `ground` in dark.
- `menab-logo-ink.png`: charcoal (`ink` light value) for the app in light mode, documents and PDFs.
- `menab-mark-light.png`, `menab-mark-ink.png`: the mark alone, for app icons, favicons and tight headers.
- `menab-mark-ember.png`: the mark in Storyflow orange (`accent`), for rare moments only, such as the loading screen.

Keep clear space equal to the height of the "e" around the logo. Never stretch, outline, add shadows or place the logo on busy images. An SVG version and an Arabic wordmark (مِناب) are still needed from the designer.
